步骤 1 · 选平台

AutoDL 用启动接口拉起；RunPod 填 API Key + 机器码（Pod ID）一键开机。

步骤 2 · AutoDL 启动接口

自定义服务开公网：6008 填启动接口；Comfy 公网（6006）填在步骤 3。

填好步骤 3 的 Comfy 地址后，点「拉起 Comfy」；接口会在实例里跑 boot 脚本。

步骤 2 · RunPod 凭证

在控制台复制 机器码（Pod ID）；API Key 在 Settings → API Keys。都只存在本机浏览器，不会上传到本站。

公网形如 https://<机器码>-<端口>.proxy.runpod.net。模板须暴露该 HTTP 端口，Comfy 监听 0.0.0.0。

本页可放任意静态托管；填 AutoDL/Comfy 公网地址（不要加端口）后点「连接」。 跨域常被 CORS 拦：需 Comfy 开 CORS（如 --enable-cors-header）、或用 nginx / Cloudflare Worker / 本目录 cors_proxy.py 同源反代。 可点「导入外部 PNG 工作流」从相册/文件选任意 Comfy PNG 读元数据；生成显示「出图中 x/y 步」；图保存在本机浏览器图库，清缓存会丢；实例关机前 Comfy output 也有原图。 图库点「选择」勾选后，点「存到相册」会打开系统分享（选「存储图像」/「存储到相册」）；勾选「存相册成功后删除服务器原图」且分享成功时，会删 Comfy 卷上对应 output 文件（需已装 custom_nodes/vreny_output_api）。不支持分享时请打开大图长按保存（长按不会自动删服务器文件）。
